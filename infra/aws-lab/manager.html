환경 설정

교육별 이름으로 저장 · 재사용
네트워크는 공유하고, 서버·IAM 권한·S3·DB는 학생별로 분리합니다. 집 IP 등록과 SSH 개인 키는 필요하지 않습니다.
아직 저장하지 않았습니다.
재사용 범위와 주의사항

새 교육 이름으로 같은 구성을 저장하거나 서버 사양·S3·DB 선택을 바꿀 수 있습니다. 이미 생성된 자원을 설정 저장만으로 변경하지는 않습니다. 새 학생 추가는 새 학생만 선택해 생성하세요. 실제 비용과 EC2·RDS 한도는 배포 전에 별도로 확인해야 합니다.

학생 강의실과 연결

위 학생 목록에 LMS 이메일을 입력하고 설정을 저장하세요. 학생은 해당 과정 수강 승인 상태여야 합니다.

LMS 관리자 → 실습 환경 배정 → 전송 토큰 발급. 15분 유효 · 한 번 성공하면 사용 종료. AWS 관리자 키는 보내지 않습니다.

학생 본인 화면에서만 접속 정보를 확인·다운로드할 수 있도록 연결합니다.
