# 구현 계획과 검증 상태

## 확정 구성
- Lightsail Ubuntu 24.04 / 2 vCPU / 4 GB / 80 GB
- Next.js + PostgreSQL 16 + Prisma. 영상은 비공개 S3 + CloudFront로 분리.
- GitHub에서 코드 관리, 운영자가 서버 배포. 기존 해커톤 서비스와 독립.
- 자체 제작 슬라이드·내레이션 영상 16편. 실제 콘솔 실습은 별도 검증 필요.

## 단계
1. 기본 구조와 교육과정 안내 (현재 구현)
2. 비밀번호 해시, 서버 세션, 동일 출처 Server Actions·속도 제한, 관리자 초기 생성, 수강 승인 (구현; 실제 PostgreSQL 통합 검증 대기)
3. 서버 재생 세션과 연속 시청구간 검증, 접근 권한 확인, 이어보기 (구현; 실제 DB·브라우저 검증 대기)
4. 실습 텍스트·URL 제출·퀴즈·온라인 수료 기준·CSV 보고서 (구현; 통합시험 대기)
5. 자체 영상 제작·자막·콘텐츠 검수·S3 업로드
6. DB 마이그레이션·백업/복원·배포·부하 검증

## 필수 검증
- 다른 학생 기록 접근 거부, 미승인 학생 콘텐츠 접근 거부
- 변조된 위치·시간·동시 세션으로 진도가 증가하지 않음
- 새로고침/기기 변경 이어보기, 네트워크 단절 저장 안내
- 비밀번호·학생 정보·서명 키·콘텐츠 원본 Git 제외
- 영상 교체 시 버전별 진도 처리
- DB 백업 복원 후 계정·진도 일치

현재 안내 화면은 학습 기능이 있는 것으로 표시하지 않는다. 서버 배포는 인증·권한과 운영 검증 완료 후 진행한다.


## 2단계 검증 기록
- 비밀번호 해시: salt 고유성·일치/불일치·비정상 해시·길이 제한 테스트.
- Prisma Client 생성 및 초기 SQL 마이그레이션 생성.
- PostgreSQL 및 Docker가 현재 작업 환경에 없어 실제 DB 기반 가입/로그인/승인 통합시험은 미실행.
- 브라우저 화면 QA 및 Lightsail 배포는 미실행.
- 개인정보 안내 미확정 상태에서는 가입 기본 차단 (`ENABLE_REGISTRATION=false`).


## 3단계 범위
- 승인 학생·이전 강의 버전별 이수 확인 후 학습 페이지/API 접근.
- 경과시간 기반 진도 검사, 중복 합산 방지, 낙관적 잠금으로 동시 저장 충돌 거부.
- 같은 학생·강의의 재생 세션 교체, 120초 유휴 만료.
- 비공개 MP4 Range 전송, 영상 길이 검사·버전 등록 도구.
- 완료 전 1배속과 탐색 제한, 완료 후 자유 탐색, 저장 실패 시 재생 정지 안내.
- 실제 영상은 제작·업로드 전. 영상 없음 상태를 명확히 표시.
- 같은 계정의 서로 다른 강의 동시 재생 제한, 자막·S3/CDN은 후속 구현.


## 4단계 검증 범위
- 서버 채점, 미응답·변조 답안 거부, 70점 통과 및 모든 항목의 온라인 기준 계산.
- 실습 URL 프로토콜·인증정보 제한, CSV 특수문자 이스케이프 및 수식 주입 방지 단위 테스트.
- 같은 학생의 승인된 수강 과정만 제출·평가 접근, 관리자 전용 검토·CSV API.
- 수정 제출 시 검토 대기로 전환, 관리자 검토 시 updatedAt 비교로 오래된 제출물 승인 방지.
- 실제 PostgreSQL 연계시험·브라우저·CSV 다운로드 실사용 시험 미실행.
- 파일 직접 업로드·공식 수료증·대면 출석·최종 프로젝트 평가 연계는 미구현.

## 5단계 진행 상태
- AWS 01 원본 대본·화면·합성 음성·문장 단위 자막 영상 제작: 348.144초, H.264/AAC, 1920×1080.
- 앞/뒤 장면 PNG 레이아웃과 ffprobe 스트림·길이·파일 크기 확인.
- 최종 청취 검수, 실제 학습 계정 재생·이어보기 시험 및 서버 업로드 미실행.
- 나머지 영상 15편은 제작 전. 전체 콘텐츠 완료로 표시하지 않음.
- LMS에 선택형 한국어 WebVTT 자막 전송·등록 경로 추가. 빌드·타입 검사·테스트 16개 통과.


## 콘텐츠 후속 제작

- 제작 완료 수는 2편, 나머지 14편은 제작 전. 서버 업로드는 미실행.
