## 코드 수정
- MP3 컨테이너 길이만 신뢰하지 않고 실제 PCM 샘플 수로 음성 길이를 측정합니다.
- 대본 전체가 문장 메타데이터에 포함되는지, 마지막 문장이 음성 길이 안에 있는지 검사합니다.
- 캐시에 음성 해시와 샘플 수를 남기고 불완전한 음성을 재사용하지 않습니다.
- 24,000 Hz 음성과 15 fps 화면을 장면마다 정확한 정수 프레임으로 맞춥니다.
- 마지막 발화 후 최소 0.4초 화면 유지 시간을 둡니다.
- 문장 구간과 자막, 화면 전환을 동일한 프레임 시간표에서 생성합니다.
- 설명 포인트를 문장 수에 따라 임의로 이동하던 방식을 제거했습니다. 확실히 일치하는 주제가 있을 때만 강조하며 불확실하면 강조하지 않습니다.
- 퀴즈 정답 강조는 '정답은'이라는 해설이 시작된 이후에만 공개합니다.
- 외부 음성 합성은 기본 비활성화입니다. 별도 명시적 허용 없이는 대본을 전송하지 않습니다.

## 검증과 복구
타이밍·누락 발화·강조 제어 단위검사 6개 통과. PCM/프레임 수, 장면 경계, 음성 끝 유지 시간, 인코딩 후 스트림 길이와 전체 디코딩을 점검하는 오프라인 검사 도구를 추가했습니다.

사용자의 명시적 허용 후 기존 음성 합성 서비스에 해당 8개 장면의 강의 대본만 전달해 재합성했습니다. 16편 모두 PCM·프레임 고정 방식으로 재제작하고, 인코딩된 실제 음성의 장면 시작 위치를 원본 PCM과 비교하고 화면 전환 프레임을 생성 원본과 비교합니다. 상세 결과는 video-sync-verification.json에 기록합니다. 최종 전 구간 청취·발음 검수와 실제 S3 재생 확인은 별도입니다.
