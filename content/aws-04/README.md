# aws-04 — EC2 생성과 웹 서버 실행

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

## 장면 구성
1. 오늘의 결과물 / 내 페이지 한 장
2. 생성 전에 여섯 항목 확인
3. 먼저 서버 안에서 확인하기
4. 페이지와 파일 경로를 연결하기
5. 문제 / 내부는 되는데 외부는 안 된다
6. 외부 확인은 실제 사용자 관점
7. 직접 미션 / 한 곳만 바꾸어 보기
8. 복습 / 생성보다 검증이 중요하다
