# AWS 01 — 실습 시작과 계정·비용 확인

직접 작성한 개념·실습 준비 안내 영상입니다. 실제 콘솔 녹화가 아닙니다.

## 학습 목표
- 제공 계정과 리전, 실습 권한을 확인한다.
- 예산 알림과 자원 정리의 역할을 구분한다.
- 실습 작업 기록과 종료 체크리스트를 작성한다.

## 실습 (영상 외)
1. 운영자 제공 접속 안내와 계정 별칭을 확인한다. 비밀번호는 기록하지 않는다.
2. 지정 리전을 확인한다. 안내가 없으면 운영자에게 문의한다.
3. 허용 서비스·사양·기간과 오류 문의 방법을 기록한다.
4. 자원 종료·정리 기준을 확인한다. 공용 자원은 임의 삭제하지 않는다.

## 확인 질문
- 만든 인스턴스가 보이지 않을 때 먼저 확인할 두 가지는?
- 권한 오류가 발생하면 누구에게 어떤 정보를 전달해야 하는가?
- 브라우저 종료만으로 과금 자원이 정리되는가?

## 제작·검수
원본은 lesson.json. 음성 발음·속도·자막·자료 일치 여부의 최종 청취 검수가 필요합니다.
출처 링크는 lesson.json에 기록되어 있습니다. UI 메뉴 위치와 실제 계정 권한은 실습 환경에서 별도 검증합니다.
