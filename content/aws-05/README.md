# aws-05 — S3 업로드와 접근 권한

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

## 장면 구성
1. 파일이 올라갔는데 왜 403일까?
2. 버킷과 객체 키를 주소처럼 읽기
3. 비공개를 기본으로 시작하기
4. 문제 / 교육 영상이라면 모두 공개?
5. 업로드 후 크기·유형·내용 확인
6. 정적 사이트와 강의 보관을 구분
7. 직접 미션 / 비공개 파일 확인
8. 복습 / 저장과 제공을 나누자
