# nhn-07 — 모니터링과 장애 확인

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

## 장면 구성
1. 학생은 느리다는데 서버는 실행 중?
2. CPU 하나로 모든 장애를 설명하지 않기
3. 로그는 사건의 흔적
4. 서버 내부의 작은 점검 도구
5. 문제 / 바로 재시작하면 충분할까?
6. 알림에는 대응 기준이 필요
7. 직접 미션 / 5줄 장애 기록
8. 복습 / 근거로 점검 순서를 고르기
