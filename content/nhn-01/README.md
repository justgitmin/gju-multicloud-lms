# nhn-01 — 조직·프로젝트·권한 확인

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

## 장면 구성
1. 콘솔이 달라져도 먼저 확인할 것
2. 조직과 프로젝트의 역할 구분
3. 초대와 역할이 준비되었는지
4. 문제 / 자원이 사라졌을까?
5. 인증정보는 용도에 따라 다르다
6. 비용과 사용 범위를 먼저 정하기
7. 직접 미션 / 실습 환경 카드
8. 복습 / 위치·권한·범위
