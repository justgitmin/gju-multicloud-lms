# aws-08 — 결과 제출과 리소스 정리

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

## 장면 구성
1. 잘 만들었다는 것을 어떻게 보여줄까?
2. 제출물은 네 가지 질문에 답하기
3. 증빙에 비밀정보가 없는지 확인
4. 문제 / 서버 중지면 비용은 모두 끝?
5. 정리 순서는 의존성을 따라
6. 삭제 후에도 목록으로 재확인
7. 직접 미션 / 제출과 정리 체크리스트
8. 다음 단계 / 같은 원리로 다른 클라우드
