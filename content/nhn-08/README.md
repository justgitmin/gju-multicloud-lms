# nhn-08 — 서비스 매핑과 자원 정리

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

1. 이름 맞추기보다 역할 비교
2. 컴퓨팅과 네트워크 비교
3. 스토리지와 데이터베이스 비교
4. 문제 / 멀티클라우드면 무조건 더 좋을까?
5. 최종 설계는 요구사항에서 시작
6. 발표와 제출은 근거 중심으로
7. 직접 미션 / 비교표와 정리 목록
