# AWS 02 — VPC·Subnet·라우팅 이해

## 수업 구성
1. 장애 상황으로 시작: 실행 중인 서버에 접속되지 않는다.
2. 네트워크 경계와 서브넷을 단계적으로 추가한다.
3. 라우팅 테이블에서 목적지와 다음 경로를 연결한다.
4. 예측 문제: public이라는 이름만으로 인터넷에 연결되는가?
5. 직접 공인 IPv4 접속의 조건을 확인한다.
6. 웹·DB 역할과 필요한 통신을 구분한다.
7. 장애 문제를 풀고 3분간 직접 구조를 그린다.
8. 주소·길·문이라는 세 가지 점검 관점으로 복습한다.

## 집중도를 위한 장치
- 문장 단위 자막과 함께 현재 설명 포인트를 강조한다.
- 네트워크 도식·라우팅 표·선택 문제·미션으로 화면 유형을 바꾼다.
- 문제는 먼저 제시하고, 해설에서 정답을 공개한다.
- 연습 시간은 학생이 일시정지해 확보한다. 대기 화면으로 영상 시간을 늘리지 않는다.

## 미션 (영상 밖 약 3분)
VPC 안에 웹 구역과 DB 구역을 그리고 사용자→웹→DB 통신을 표시한다.
인터넷 직접 접근이 필요한 자원과 라우팅·접근 제어 조건을 설명한다.

## 검수 기준
- 인터넷 게이트웨이 경로가 있는 서브넷과 인터넷 접근 가능한 인스턴스를 구분한다.
- 예시는 IPv4 직접 접속이며 로드밸런서·프록시 구성 전체를 설명하지 않는다.
- DB 서브넷 그림은 역할 설명용이며 RDS의 다중 AZ 서브넷 조건을 대체하지 않는다.
- 실제 콘솔 녹화가 아니며 실제 계정·권한 환경의 실습 검증은 별도로 수행한다.
- 최종 청취와 학습자 재생·이어보기 검증 전의 검수용 초안이다.
