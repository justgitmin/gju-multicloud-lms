# nhn-04 — 같은 웹 애플리케이션 배포

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

## 장면 구성
1. 앱은 같게, 플랫폼은 다르게
2. 파일과 실행 환경을 먼저 확인
3. Nginx 설치와 내부 응답 확인
4. 한 파일이 아니라 앱 전체 배포
5. 문제 / 글자는 보이는데 스타일이 없다
6. 두 클라우드의 결과를 같은 표로
7. 직접 미션 / 동일 앱 비교 증빙
8. 복습 / 결과는 같고 운영 조건은 다르다
