# aws-07 — IAM 최소 권한과 운영 점검

자체 제작 설명·실습 안내 영상입니다. 실제 클라우드 콘솔 녹화가 아닙니다.
실제 계정의 권한·리전·과금·자원 상태를 확인한 뒤 실습하세요.
명령어 화면은 예시이며 실행 결과를 보증하지 않습니다.
최종 청취·실습 환경 검수와 학생 재생 시험은 별도로 필요합니다.

## 장면 구성
1. 서버에 들어가면 S3도 마음대로 쓸까?
2. 정책을 세 질문으로 읽기
3. 역할과 임시 자격 증명
4. 문제 / 업로드가 안 되면 관리자 권한?
5. 오류 공유에 필요한 정보
6. 운영 점검: 만들기 전과 후
7. 직접 미션 / 권한 요청 한 줄
8. 복습 / 편리함보다 필요한 범위
